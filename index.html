How to use Dual Grid Studio

1. Paint a tile

Pick a tile from the atlas, draw in the big editor, and the atlas thumbnail plus the neighbour preview update immediately. Each tile represents one corner mask, and #0 is the editable base/background fill (the sample uses brown dirt).

Use the Variations bar to create alternate art for the same mask. The live preview picks variations stably by map position, and edge sync keeps every variation seamless.

2. Test neighbours

The editor shows the centre tile at full size with compatible neighbours around it at 50% opacity. Click a margin's # label to load any tile that connects in that slot, then draw across the seam to keep it continuous. With Sync edges on, the matching edge pixels are copied into every compatible neighbouring mask and every variation, so the margin slots update as you paint. Use the zoom controls or Ctrl/⌘ + wheel to zoom, and toggle the thin Centre border off if it gets in the way.

Paint the test map under Neighbour Preview. The preview resolves every 2×2 corner mask and picks the matching tile, so you can check edges and inner corners before exporting.

3. Build a design

A design can contain several grids. An outer grid renders first and an inner grid renders on top. Toggle All grids to see the composite.

4. Export

Choose a 3×3 atlas (9 outer-edge masks) or a 4×4 atlas (15 masks + the editable #0 base fill). Set gap, margin, scale and background in the Export panel.
